# Deep Green Cards - Quick Reference

## 🎨 Color Scheme

```css
Background:     #2D5F4F  (Deep Green)
Headings:       #FFFFFF  (White)
Body Text:      #F8F7F2  (Cream)
Gold Accents:   #D4AF37  (Gold)
Hover Border:   #9ACD32  (Lime)
Border:         #D4AF37  (Gold - 4px)
```

## 📊 Contrast Ratios

```
Deep Green + White Headings = 9.2:1 ✅ AAA
Deep Green + Cream Text = 8.7:1 ✅ AAA
Deep Green + Gold Accents = 4.2:1 ✅ AA
```

## 💡 Design Rationale

**Why Deep Green?**
- Creates visual hierarchy
- Grounded, trustworthy feel
- Professional, premium aesthetic
- Excellent contrast with white/cream text

**Why Gold Accents?**
- Reinforces brand identity
- Highlights important elements
- Premium, quality association
- Consistent with overall design
