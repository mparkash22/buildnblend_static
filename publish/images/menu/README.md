# Menu Images

This directory contains menu item photos.

## Image Specifications
- Format: WebP with PNG/JPG fallback
- Aspect Ratio: 16:9
- Card size: 450x253px
- Expanded view: 1200x675px
- File size target: <100KB

## Required Images
- At least 18 menu item photos across all categories
- Burritos, Bowls, Wraps & Shawarma, Tacos, Falafel & Chickpea, Beverages
