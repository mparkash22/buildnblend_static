## Image Guidelines

### Testimonial Photos
- Format: WebP with PNG fallback
- Dimensions: 150x150px (will be displayed as circular)
- File size: < 50KB each
- Style: Professional headshots with good lighting
- Diversity: Show diverse customers (students, professionals, families)

### Instagram Feed Images
- Format: WebP with PNG fallback
- Aspect ratio: 1:1 (square)
- Dimensions: 400x400px minimum
- File size: < 100KB each
- Style: Vibrant food photography, lifestyle shots, community moments

### Blog Images
- Format: WebP with PNG fallback
- Aspect ratio: 16:9
- Dimensions: 800x450px
- File size: < 150KB each
- Style: High-quality photography related to blog topics
