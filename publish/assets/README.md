# Assets

This directory contains logo files, favicon, and other brand assets.

## Required Files
- logo.svg - Main logo (gold B with lime green neon ring)
- logo-white.svg - Inverse logo for dark backgrounds
- favicon.ico - Browser favicon (16x16, 32x32, 48x48)
- apple-touch-icon.png - iOS home screen icon (180x180)

## Logo Specifications
- Format: SVG (scalable)
- Style: Modern luxury neon aesthetic
- Colors: Gold (#D4AF37) and Lime Green (#9ACD32)
